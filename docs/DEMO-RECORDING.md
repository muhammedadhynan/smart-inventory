# Short project demo recording

Aim for a clear 1–2 minute video showing the finished live web app. Use Chrome or the NexaStock Android app and use sample data where possible.

## Submitted recordings

- [Web app screen recording](https://drive.google.com/file/d/1zaggB4ief6QAXbvhJWH85XnkZQRPmSc6/view?usp=sharing)
- [Android app screen recording](https://drive.google.com/file/d/1ickeMXeTl7A-Ddr7oc_jHQBQ9wBaF7IV/view?usp=sharing)

## Suggested recording order

1. Show the NexaStock sign-in screen and sign in without showing or saying the password.
2. Show the Overview dashboard and its inventory totals and recent activity.
3. Open Products and show the product list and name search.
4. Open Categories and Customers briefly.
5. Open Orders, show an order and its status or invoice.
6. Finish on the live app homepage or dashboard.

Use existing sample records; do not create test orders that change real stock during the recording.

## Record on Windows

1. Open the live web app: https://nexastock-inventory-g4xy.onrender.com/
2. Press **Windows key + Alt + R** to start Xbox Game Bar recording. Press the same keys to stop.
3. Check **Videos → Captures** for the MP4 file.
4. Play the video once to confirm it is readable and the audio is clear if you used narration.
5. Upload the MP4 file to the company submission page.

Before recording, close unrelated tabs and hide passwords, private customer details, database settings, and any secret keys. The submission recording should demonstrate the app without exposing credentials or private data.
